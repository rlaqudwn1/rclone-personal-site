개인정보처리방침

적용일: 2026년 10월 12일 · 대상: rclone-personal 개인용 OAuth 앱과 이 안내 사이트

1. 사용 목적과 운영 방식

rclone-personal은 계정 소유자가 자신의 Google Drive를 자신의 장치에서 rclone으로 관리하기 위해 사용하는 개인용 앱입니다. 공개 가입 서비스나 별도의 파일 처리 서버를 운영하지 않습니다.

2. Google Drive 데이터 접근

이 구성은 https://www.googleapis.com/auth/drive 권한을 사용합니다. Google의 승인을 받은 rclone은 Google Drive 파일 내용과 파일·폴더 이름, 식별자, 크기, 수정 시간 등의 메타데이터를 읽을 수 있으며, 계정 소유자가 실행한 명령에 따라 파일을 다운로드·생성·업로드·수정·삭제할 수 있습니다. 이 권한은 애플리케이션 데이터 폴더를 제외한 Drive 파일 전반에 적용됩니다.

접근한 데이터는 요청한 개인 파일 관리 작업을 수행하는 데 사용됩니다. 사용자 데이터를 광고, 판매, 외부 분석 또는 AI 모델 학습에 사용하지 않습니다.

3. 처리 위치와 데이터 전달

rclone은 본인의 장치에서 실행되어 Google OAuth 및 Google Drive API와 직접 통신합니다. 다운로드한 파일은 명령에 지정한 로컬 위치에 저장되고 업로드한 파일은 본인의 Drive에 저장됩니다. 계정 소유자가 다른 저장소로 복사하는 명령을 직접 실행하면 해당 대상에도 데이터가 전달될 수 있으며, 그 작업은 이 정적 안내 사이트에서 실행되지 않습니다.

이 사이트와 공개 소스 저장소에는 Drive 파일 내용, OAuth 자격 증명, 토큰 또는 rclone 설정 파일을 게시하지 않습니다. Google의 데이터 처리는 Google 개인정보처리방침의 적용을 받습니다.

4. 자격 증명 저장과 보관

OAuth Client ID, Client Secret 및 발급된 토큰은 본인의 장치에서 rclone 설정에 로컬로 저장됩니다. 토큰은 사용자가 연결을 유지하는 동안 인증 갱신에 사용될 수 있습니다. 로컬 설정의 파일 접근 권한과 장치 보안은 계정 소유자가 관리합니다. rclone의 기본 저장이 자동으로 암호화된다는 의미는 아니며, 필요하면 rclone 설정 암호화와 장치 암호화를 직접 구성할 수 있습니다.

이 웹사이트에는 토큰·파일을 수집하거나 보관하는 백엔드가 없습니다. 다운로드한 파일과 로컬 설정은 사용자가 삭제할 때까지 장치에 남을 수 있으며, Drive의 파일·휴지통 보관은 Google Drive 설정에 따릅니다.

5. 접근 철회와 삭제

Google 계정의 서드 파티 연결 관리에서 rclone-personal의 접근을 제거할 수 있습니다. 이후 rclone의 해당 remote와 로컬 자격 증명·토큰을 직접 제거할 수 있습니다. 로컬 설정 제거만으로 Google 측 승인이 항상 철회되는 것은 아니므로 Google 계정에서도 연결을 제거하세요. 승인을 철회해도 이미 내려받은 파일이나 기존 Drive 파일은 자동 삭제되지 않습니다.

6. 이 웹사이트의 호스팅과 접속 로그

이 안내 사이트는 GitHub Pages에 호스팅된 정적 HTML/CSS 페이지입니다. 운영자가 추가한 분석·광고 스크립트, 쿠키, 입력 폼은 없습니다. GitHub는 호스팅 보안을 위해 방문자의 IP 주소를 기록·저장합니다. 이러한 웹사이트 접속 로그는 OAuth 승인 및 rclone의 Google Drive 데이터 접근과 별개입니다. 자세한 내용은 GitHub Pages 데이터 수집 안내와 GitHub 개인정보처리방침을 확인하세요.

7. 정책 변경

사용 목적이나 데이터 처리 방식이 바뀌면 이 페이지와 적용일을 갱신합니다. 새로운 권한이 필요하면 Google의 OAuth 동의를 다시 받아야 합니다. 이 앱은 개인용이며 계정 소유자가 OAuth 설정과 데이터 처리를 직접 관리합니다.
